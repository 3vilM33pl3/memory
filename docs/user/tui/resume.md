# Resume Tab

Use **Resume** after an interruption when you need the focused next-step briefing rather than raw activity history.

![Resume briefing in the TUI](https://www.memory-layer.dev/images/tui/resume-tab.png)

The view combines the active project, latest checkpoint, inferred work thread, primary next step, important changes, attention items, durable context, and a recent timeline. When a checkpoint exists and the project changed after it, Resume can be the first useful view to open.

## Controls

- `j` / `k`, `PgUp` / `PgDn`, and `Home` navigate a long briefing.
- `r` refreshes the resume pack.
- `h` opens help.

See also: [Daily workflow](https://www.memory-layer.dev/docs/daily-workflow) and [resume CLI](https://www.memory-layer.dev/docs/reference/cli/query-briefings).
