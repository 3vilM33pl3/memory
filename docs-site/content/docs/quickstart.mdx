# Quickstart

This is a single reproducible demo: start the bundled stack, load the demo project, and ask one question. It uses Docker only, so you do not need PostgreSQL, pgvector, or any API keys to see it work.

## 1. Start the stack

From a clone of the repository:

```bash
docker compose up
```

That starts PostgreSQL with pgvector, the Memory Layer service, and the web UI. When it settles, the service is listening on `http://localhost:4040`.

## 2. Load the demo project

In another terminal:

```bash
docker compose exec memory memory demo
```

This seeds a project called `demo` with a small, curated set of memories about Memory Layer itself.

## 3. Ask it something

```bash
docker compose exec memory memory query --project demo --question "How does reinforcement work?"
```

You get a short, cited answer drawn from the demo memories, with a confidence score and an honest signal when the evidence is thin.

## 4. Explore

```bash
docker compose exec memory memory tui
```

The terminal UI lets you browse and search every memory, inspect where each came from, and open the memory graph. The [web UI](/docs/web-ui) at `http://localhost:4040` shows the same data with wider panes and a 3D graph view.
